## Lynx Default Tabs v0.3.1 — Public Preview

This is a Lynx adaptation of **edit-unorganized by feederbox826**, with credit to the original author for the plugin and its default-tab workflow.

Choose which tab opens on scene, image and gallery detail pages. Unorganized items open on Edit by default, with an option to apply your preference to organized items too.

The Lynx version handles asynchronously loaded controls and Stash navigation without extra UI helper plugins. English settings guidance, installation instructions and the original MIT license notice are included.

### Installation

Copy `LynxDefaultTabs` into your Stash plugins directory, reload plugins, enable Lynx Default Tabs and refresh your browser. Disable the original plugin or another installed copy first.

The internal ID and manifest filename remain `edit-unorganized` to preserve existing settings. See `INSTALLATION.md` for details.

### Preview status

The package has passed syntax, asset and mocked navigation checks. A fresh installation and live UI testing have not yet been verified for this release. Please report compatibility issues.
