## Before using a preview

- Back up Stash's configuration, database and existing plugin folders.
- Back up affected media before file-moving, renaming or image-replacement operations.
- Test in a separate Stash instance with a small set of data first.
- Read the component's installation instructions, requirements and known limitations.
- Review previews before applying changes. Enable automatic processing only after testing.
- Preserve runtime databases and browser-local data where the component requires them.

Restoring plugin code alone does not undo metadata edits, portrait replacement or file operations.

The installation sources publish catalog-listed builds from the main branch. They can change independently of manually created GitHub releases. A passed build or automated test does not establish that every workflow has been verified in a real Stash installation.
