## Lynx Scraping Suite v1.0.0-rc.4 — Public Preview

This is the first public preview of Lynx Scraping Suite, a collection of performer metadata tools for Stash.

The release includes XL Girls and Mature.nl, with source search, field comparisons, optional profile-image imports and selected-performer batch review. XL Girls height and weight are converted to centimetres and kilograms, while measurements retain their original notation.

English settings, installation instructions and companion native Stash scrapers are included. Lynx Theme and the other Lynx plugins are optional.

### Installation

Copy `LynxScrapingSuite` into your Stash plugins directory. For native name/URL scraping, also copy the folders inside `scrapers` into your Stash scrapers directory. Reload both, enable the desired source modules and refresh your browser.

Python is required. See `INSTALLATION.md` for details.

### Preview status

The package has passed syntax checks and mocked source-routing, import and interface tests. A fresh installation and live scraping have not yet been verified as part of this release review. Source availability and website changes can affect results. Please report any issues.
