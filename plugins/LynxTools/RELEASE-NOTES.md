## Lynx Tools v1.0.0-rc.2 — Public Preview

This is the first public preview of Lynx Tools, a collection of optional tools for working with your Stash library.

The release brings together context menus for scenes, galleries, images, performers, tags and settings, alongside a snapping image cropper and single-eye VR viewing modes. Enable the modules you want and configure them from grouped English settings.

The shared performer picker supports full names and aliases. Lynx Theme and the other Lynx plugins are optional.

### Installation

Copy the `LynxTools` folder into your Stash plugins directory, reload plugins and enable the modules you want under **Settings → Plugins**. Refresh your browser after changing module switches.

Disable older standalone plugins that duplicate the enabled modules. See `INSTALLATION.md` for details.

### Preview status

The package has passed syntax, module-loading, settings-isolation and name/alias picker checks. A fresh installation and complete live testing of every action have not yet been verified as part of this release review. Please report any issues.
